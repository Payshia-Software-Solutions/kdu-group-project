# **App Name**: KDU Group Portal

## Core Features:

- About Us: Comprehensive 'About Us' section detailing KDU Group's history, mission, and values.
- Services Overview: Detailed 'Services' page outlining the range of services offered by KDU Group.
- Project Showcase: Interactive 'Projects' or 'Portfolio' section showcasing KDU Group's successful projects.
- Contact and Inquiry: 'Contact Us' page with a submission form for inquiries, and an LLM tool that uses reasoning to determine which company representatives should respond to a query.
- Content Suggestions: AI-powered content suggestions to generate alternative copy for the site.

## Style Guidelines:

- Primary color: Deep corporate blue (#1A5276) to convey trust and stability. This color will appear in the header.
- Background color: Light gray (#E5E8E8) to provide a neutral and professional backdrop.
- Accent color: Muted light blue (#7FB3D5) for interactive elements and highlights.
- Body text: 'Inter', a sans-serif font, providing a modern, neutral and objective feel for readability.
- Headline font: 'Space Grotesk', a sans-serif font with a computerized, techy feel.
- Use clean, minimalist icons in the muted light blue to represent different sections and services.
- Employ a clean, grid-based layout to ensure clear information hierarchy and easy navigation.
